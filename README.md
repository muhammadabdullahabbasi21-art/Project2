# Blood Donation App 🩸📱

An Android application developed using **Android Studio**, **Java**, and **XML** layouts. This project focuses on a complete user authentication and navigation flow, featuring multiple interactive screens from startup to the main dashboard.

---

## 📌 App Screens & Flow

1. **Splash Screen:** 
   - The initial loading screen displayed when the app launches before transitioning to the authentication flow.
2. **Login Activity:** 
   - Allows registered users to log into their accounts securely.
3. **Password Reset & Forgot Password Activities:** 
   - Dedicated screens for users who need to recover or reset their account credentials.
4. **Main Activity (Dashboard):** 
   - The primary interface of the app where users can access core features (such as viewing or requesting blood donations) after successful login.
